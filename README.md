# 🎬 Clone Disney+

Projeto desenvolvido como prática de construção de interface inspirada na plataforma Disney+, utilizando HTML, JavaScript e organização modular de estilos com Sass automatizado via Gulp.

## 🚀 Funcionalidades

* Estrutura de página inspirada em streaming
* Organização de estilos por componentes (header, hero, shows, planos, FAQ, etc.)
* Utilização de variáveis globais no Sass
* Processamento e automação de estilos com Gulp
* Separação entre estrutura, scripts e estilos

## 🛠️ Tecnologias Utilizadas

* HTML5
* JavaScript
* Sass (SCSS)
* Gulp
* Node.js / npm

## 📂 Estrutura do Projeto

```bash
clone_disney_plus/
├── src/
│   ├── index.html
│   ├── main.js
│   ├── images/
│   └── styles/
│       ├── _header.scss
│       ├── _hero.scss
│       ├── _shows.scss
│       ├── _plans.scss
│       ├── _faq.scss
│       ├── _footer.scss
│       ├── _available-devices.scss
│       ├── _watch-anywhere.scss
│       ├── _image-text-section.scss
│       ├── variaveis.scss
│       └── main.scss
├── gulpfile.js
├── package.json
└── package-lock.json
```

## ▶️ Como Executar

1. Instale as dependências:

```bash
npm install
```

2. Execute o Gulp:

```bash
npx gulp
```

3. Abra o arquivo gerado no navegador.
